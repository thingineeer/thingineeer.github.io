아래 내용은 앱 코드와 기존 앱별 정책에서 확인한 현재 동작을 기준으로 합니다. 선택 기능을 사용하지 않으면 해당 선택 데이터는 처리하지 않습니다.

AI 제공자의 자격 증명과 원본 사용 기록은 기기 밖으로 보내지 않습니다. 앱 개선을 위한 익명 진단(Firebase Analytics·Crashlytics)은 앱을 실행하는 동안 항상 수집하며, 랭킹 참여는 기본적으로 꺼져 있고 사용자가 켠 경우에만 관련 정보를 전송합니다. 공개 랭킹 관전은 참여하지 않아도 앱·기기 무결성 확인을 위해 서버에 접속합니다.

UsageMaster는 AI 답변이나 콘텐츠를 생성하지 않고, 연결된 AI 도구의 사용량을 로컬에서 표시합니다.

기기 안에서 처리하는 것

  • 로컬 기록형 provider(Claude, Codex, OpenCode Go 등)는 각 도구가 이 Mac 에 남긴 사용량 파일·데이터베이스만 읽으며 외부로 전송하지 않습니다.
  • Provider가 소유한 인증 토큰은 사용량 조회 중에만 읽고 앱 Keychain에 복사하거나 로그·Firebase로 전송하지 않습니다.
  • CLI 자격을 재사용하는 provider(Gemini, Codex 서버 조회 등)는 도구가 저장한 액세스 토큰을 공식 사용량 API 요청 1회에만 쓰고 즉시 폐기합니다. 토큰을 갱신(refresh)하지 않습니다.
  • 사용자가 직접 붙여넣은 API 키·Cookie header 는 이 앱 전용 Keychain(이 기기만, 동기화 없음)에만 저장하고 그 provider 의 공식 사용량 API 요청 헤더에만 씁니다. 설정에서 언제든 삭제할 수 있으며 화면·로그·진단·랭킹 어디에도 나가지 않습니다.
  • Pro 의 Claude 계정 전환은 로그인 토큰 블록을 이 앱 전용 Keychain 에 보관했다가 Claude Code 항목에 그대로 옮깁니다. 토큰을 갱신하거나 서버로 보내지 않으며, 계정 이메일 확인을 위한 프로필 조회만 원문 1건당 최대 1회 합니다.
  • 연결된 계정 이메일은 로컬에서 화면 표시용으로만 사용하며, 영속 저장하거나 외부로 전송하지 않습니다.
  • 프롬프트·응답·코드·파일 내용·API 키·토큰·이메일은 서버 분석 이벤트나 랭킹 요청에 포함하지 않습니다.

필수 통신

Firebase Remote Config는 최소 지원 버전과 App Store 업데이트 안내에만 사용하며, AI 사용량·이메일·토큰·프롬프트·응답·파일 내용은 요청에 포함하지 않습니다.

이때 Firebase 설치 식별자와 IP 같은 기술 정보가 처리됩니다. 공개 랭킹을 열면 조회 기간, DeviceCheck 기반 App Check 토큰과 함수 호출 IP 가 앱 인증과 부정 사용 방지를 위해 처리됩니다. 관전만 할 때는 Firebase Auth 계정이나 랭킹 소유권 데이터를 만들지 않습니다.

익명 진단 (항상 수집)

전송하는 항목은 앱 버전·언어·시간대, 앱 실행·화면 열기·새로고침·provider 연결 상태 같은 사용 흐름과 크래시 리포트입니다. 분석 이벤트에는 임의 식별자가 연결되며 크래시 리포트에는 별도 사용자 ID를 설정하지 않습니다. 사용량 수치·토큰·프롬프트·이메일·파일 경로는 전송하지 않으며, 앱 안에서 끄는 설정은 없습니다.

문의

Effective August 29, 2026Last updated September 24, 2026

AI provider credentials and original usage logs are never sent off the device. Anonymous diagnostics for improving the app (Firebase Analytics and Crashlytics) are always collected while the app is running, while ranking participation is off by default and related information is sent only if the user turns it on. Even without participating, viewing the public ranking connects to the server to verify app and device integrity.

UsageMaster does not generate AI responses or content; it displays usage of connected AI tools locally.

What is processed on-device

  • For local-record providers (Claude, Codex, OpenCode Go, etc.), only the usage files and databases each tool has left on this Mac are read, without sending them externally.
  • Provider-owned authentication tokens are read only while checking usage. They are not copied to the app Keychain or sent to logs or Firebase.
  • For providers that reuse CLI credentials (Gemini, Codex server lookup, etc.), the access token the tool has stored is used only once for an official usage API request and is discarded immediately afterward. The token is not renewed (refresh).
  • An API key or Cookie header the user pastes in is stored only in this app's dedicated Keychain (this device only, no sync) and used only in that provider's official usage API request header. It can be deleted at any time in Settings and never appears on screen, in logs, in diagnostics, or in the ranking.
  • Claude account switching in Pro stores the login token block in this app's dedicated Keychain, then transfers it unchanged to the Claude Code entry. The token is not renewed or sent to a server; at most one profile lookup per original account is made, solely to confirm the account email.
  • Connected account emails are used locally for display only, and are never stored persistently or sent externally.
  • Prompts, responses, code, file contents, API keys, tokens, and emails are never included in server analytics events or ranking requests.

Essential communications

Firebase Remote Config is used only for the minimum supported version and App Store update notices. Requests do not include AI usage, email, tokens, prompts, responses, or file contents.

In that case, technical information such as the Firebase installation identifier and IP address is processed. Opening the public ranking processes the query period, a DeviceCheck-based App Check token, and the function-call IP address for app authentication and abuse prevention. When only viewing, no Firebase Auth account or ranking ownership data is created.

Anonymous diagnostics (always collected)

What's sent is the app version, language, and time zone, plus usage flow such as app launches, screen opens, refreshes, and provider connection status, along with crash reports. Analytics events are linked to a random identifier, and crash reports do not set a separate user ID. Usage figures, tokens, prompts, emails, and file paths are never sent, and there's no in-app setting to turn this off.

Deleting the app stops collection, and deletion of diagnostic data already sent can be requested via the email below.

Ranking participation and opt-out

When ranking participation is on, the anonymous Firebase authentication identifier, public nickname, Pro status, Locale country/region code, daily, weekly, and yearly usage buckets, per-provider buckets, activity-time buckets, and Kimi request count and submission time are processed. Token counts are rounded down to the nearest 1,000.

Turning participation off stops further submissions and lookups of your identifiable rank, but already-stored server data is not automatically deleted. Please request deletion of the nickname, anonymous authentication, and aggregated data on the server via the email below.

Feedback

Feedback is sent directly from the app to UsageMaster's Firebase backend and stored there. It never goes through a mail app.

The only items stored are title, type, message, app version, macOS version, app language, distribution channel (App Store or Direct), and the anonymous Firebase ID. Email addresses, accounts, usage data, file paths, and tokens are not included.

To have stored feedback deleted, email the support address dlaudwls1203@gmail.com.

Data processors and international transfers

  • Processor: Google LLC and the Firebase and Google Cloud sub-processors Google publicly discloses. Apple processes App Store payments and restores, and DeviceCheck.
  • Purpose: Remote Config update notifications, App Check app and device integrity verification, providing the public and participation rankings, anonymous diagnostics via Analytics and Crashlytics, and storing and responding to feedback.
  • Items transferred: the essential communications, anonymous diagnostics, ranking participation, and feedback items described above. Does not include AI tool authentication tokens, emails, prompts, responses, code, file contents, or original usage logs.
  • Country/location: ranking and feedback Cloud Functions are processed and stored in Iowa, USA (us-central1), while Firestore is processed and stored in the central US multi-region (nam5). Analytics, Crashlytics, Remote Config, and App Check may be processed in the United States or any other country where Google or its sub-processors operate facilities.
  • Timing/method: transferred via encrypted HTTPS when checking for updates while the app is running, when opening or participating in the ranking, when events or crashes occur, and when sending feedback.
  • App Store purchases and restores are handled by Apple's StoreKit and the current Mac App Store account; the Apple Account email is not stored in the app.

Retention period

Crashlytics crash data and related identifiers are retained for 90 days, App Check anti-replay tokens for up to 30 days, while other App Check tokens are not retained after their validity period (up to 7 days) expires. Analytics user- and event-level data may be retained for up to 14 months.

The Remote Config installation identifier, anonymous Auth, and Firestore ranking/feedback data are retained until the operator performs deletion. Google's live and backup deletion may be subject to an additional service-specific processing period.

If you delete the app

Deleting the app removes the app container's settings and cache. Items stored in the app's Keychain - such as the once-per-device free trial record, a user-saved API key or Cookie header, a Pro account-switching token, and an anonymous analytics identifier - may remain per macOS policy and can be used after reinstallation. This does not affect each AI tool's original tokens and usage files.

User rights and objection

You can request access, correction, deletion, or suspension of processing of your data via the email below. Only the minimum additional information needed to verify your identity will be requested, and verification material will be deleted without delay after processing. If there is data that must be retained due to a legal obligation or for security and abuse-prevention purposes, you will be informed of the items and the retention period.

Ranking participation can be declined or withdrawn in Settings, and core local usage features remain usable. Anonymous diagnostics cannot be turned off within the app and stop only when the app is deleted. Blocking public ranking viewing or Remote Config communication makes the leaderboard and remote update notices unavailable.

Policy changes

This document will be updated when app features, SDKs, or legal requirements change. Material changes will be announced in the app or on the web page before taking effect, and any processing requiring additional consent will begin only after that consent is obtained.

레인 길이, 단위(미터/야드), 최대심박, 물 빼기 자동 실행, 랩 진동 설정은 시계 안에만 보관됩니다.
결제
구매·환불은 Google Play가 처리하며 개발자는 구매자의 이름·이메일·결제 정보를 받지 않습니다.
보관·삭제
기록은 사용자가 삭제하거나 앱을 삭제할 때까지 시계에만 남습니다. 앱을 삭제하면 모든 기록과 설정이 함께 제거되며, 서버에 저장되는 데이터는 없습니다. 시계 설정에서 권한을 언제든 철회할 수 있습니다.

공통 처리 원칙

  • 앱 기능 제공에 필요한 최소 정보만 처리하고, 광고·분석·알림처럼 선택 가능한 기능은 운영체제 및 지역별 동의 절차를 따릅니다.
  • 앱에서 직접 운영하는 서버 데이터는 HTTPS로 전송하고 Firebase 보안 규칙, App Check, 데이터베이스 접근 제어 등 앱별 보호 조치를 적용합니다.
  • 광고·분석·인증·호스팅 제공자는 자체 인프라에서 기기 정보, IP 주소, SDK 식별자와 기술 로그를 처리할 수 있으며 국외에서 처리될 수 있습니다.
  • 법적 의무, 분쟁 대응, 보안·부정 사용 방지에 필요한 경우를 제외하고 목적이 끝난 데이터는 삭제하거나 식별할 수 없는 집계로 전환합니다.

외부 서비스

각 앱 카드에 표시된 서비스만 해당 앱에 적용됩니다. 서비스 제공자가 처리하는 구체 항목과 보관 방식은 아래 공식 정책에서도 확인할 수 있습니다.

Google Firebase에는 앱별로 명시한 분석·충돌·인증·서버 기능 처리를 위탁하며, 해당 정보는 서비스 제공을 위해 미국을 포함한 국외 인프라에서 네트워크 전송 시점에 처리될 수 있습니다. Apple에는 App Store 결제, DeviceCheck, 푸시 알림 등 사용한 Apple 기능에 필요한 처리를 위탁합니다. 각 앱 카드의 항목·목적·보관 및 삭제 기준이 이 공통 설명보다 우선합니다.

보관·삭제와 이용자 권리

이용자는 본인 데이터의 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 앱 안에 계정 삭제나 초기화 기능이 있으면 그 기능이 가장 빠릅니다. 앱에서 처리할 수 없거나 기기를 사용할 수 없는 경우 아래 이메일로 앱 이름과 요청 내용을 보내주세요.

  • 본인 확인에 필요한 최소 정보만 추가로 요청하며, 요청 처리 후 확인 자료를 지체 없이 삭제합니다.
  • 법령상 보관 의무나 보안·부정 사용 방지상 필요한 데이터가 있으면 항목과 기간을 안내합니다.
  • Google Play에서 계정을 만드는 앱은 앱 내부와 외부 웹 경로 모두에서 삭제 요청 방법을 제공합니다.
  • 앱을 삭제하면 기기 샌드박스의 로컬 데이터는 제거되지만, 서버 데이터나 제3자 SDK 데이터는 별도 삭제 요청이 필요할 수 있습니다.

방침 변경

앱 기능, SDK 또는 법적 요구사항이 바뀌면 이 문서를 갱신합니다. 중요한 변경은 시행 전에 앱 또는 이 페이지에서 알리고, 추가 동의가 필요한 처리는 동의를 받은 뒤 시작합니다. 각 앱의 스토어 Data safety·App Privacy 답변도 실제 처리와 일치하도록 함께 관리합니다.
