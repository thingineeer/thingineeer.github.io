UsageMaster

macOS

AI 제공자 자격 증명과 원본 사용 로그는 기기 밖으로 보내지 않습니다. 진단 공유와 랭킹 참여는 기본적으로 꺼져 있으며, 사용자가 각각 선택한 경우에만 관련 정보 전송을 시작합니다. 공개 랭킹 관전은 참여하지 않아도 앱·기기 무결성 확인을 위해 서버에 접속합니다.

필수 통신
최소 지원 버전과 업데이트 안내를 확인하는 Firebase Remote Config가 Firebase 설치 식별자와 IP 등 기술 정보를 처리합니다. 공개 랭킹을 열면 조회 기간, DeviceCheck 기반 App Check 토큰과 함수 호출 IP가 앱 인증과 부정 사용 방지를 위해 처리됩니다. 관전만 할 때는 Firebase Auth 계정이나 랭킹 소유권 데이터를 만들지 않습니다.
선택 진단
사용자가 진단 공유에 동의한 동안에만 임의 UUID, 앱 버전·언어·시간대, 앱·설정·제공자 상태 같은 기능 상호작용과 Crashlytics의 충돌·기기·OS 진단을 처리합니다. 언제든 동의를 철회할 수 있으며 철회 즉시 새 Analytics·Crashlytics 수집을 중지하고 전송 대기 중인 충돌 보고서를 삭제합니다.
선택 참여
사용자가 랭킹 참여를 켜면 Firebase 익명 인증 식별자, 공개 닉네임, Locale 국가·지역 코드, 일간·주간·연간 사용량 버킷, 제공자별 버킷, 활동 시간 버킷, Kimi 요청 수와 제출 시각을 처리합니다. 토큰 수는 1,000단위로 내림 처리합니다.
참여 철회
랭킹 참여를 끄면 이후 제출과 식별 가능한 내 순위 조회를 중지하지만 이미 저장된 서버 데이터가 자동으로 삭제되지는 않습니다. 서버의 닉네임·익명 인증·집계를 삭제하려면 아래 개인정보 문의 이메일로 요청해 주세요.
피드백
피드백은 앱이 자동 전송하지 않습니다. 사용자가 기본 메일 앱에서 최종 전송하면 발신 이메일 주소, 제목·유형·메시지, 앱 버전, macOS 버전 및 사용자가 추가한 서명·첨부가 Gmail 지원 메일함으로 전달되어 문의 답변, 오류 확인과 제품 개선에 사용됩니다.
로컬 삭제
앱 삭제 시 기기 샌드박스의 설정과 캐시는 제거됩니다. 무료 체험 사용 기록, 사용자가 저장한 Cursor Cookie header와 임의 식별자 같은 Keychain 항목은 macOS 정책에 따라 재설치 후에도 남을 수 있습니다. 원본 AI 도구 파일과 계정은 삭제하지 않습니다.
처리위탁·국외 이전 세부사항
수탁자
Google LLC 및 Google이 공개한 Firebase·Google Cloud 하위처리자. 문의는 Firebase 개인정보 페이지의 지원 경로를 이용합니다.
목적
Remote Config 업데이트 안내, App Check 앱·기기 무결성 검증, 공개·참여 랭킹 제공, 선택한 Analytics·Crashlytics 진단 처리와 Gmail 기반 고객 문의 보관·응답.
이전 항목
위 필수 통신·선택 진단·선택 참여·피드백 항목. AI 도구의 인증 토큰, 이메일, 프롬프트·응답·코드·파일 내용과 원본 사용 로그는 포함하지 않습니다.
국가·위치
랭킹 Cloud Functions는 미국 아이오와(us-central1), Firestore는 미국 중부 다중 리전(nam5: 아이오와·오클라호마·사우스캐롤라이나)에서 처리·보관됩니다. Analytics, Crashlytics, Remote Config, App Check와 Gmail은 미국을 포함해 Google 또는 하위처리자가 시설을 운영하는 국가의 글로벌 인프라에서 처리될 수 있습니다.
시점·방법
앱 실행 중 업데이트 확인, 랭킹 열기·참여, 진단 동의 후 이벤트·충돌 발생, 사용자가 메일 전송을 확정하는 시점에 암호화된 HTTPS 또는 사용자의 메일 전송 경로로 이전됩니다.
보유기간
Crashlytics 충돌 자료와 관련 식별자는 90일, App Check 재사용 방지 토큰은 최대 30일이며 그 밖의 App Check 토큰은 유효기간(최대 7일) 후 보관하지 않습니다. Analytics 사용자·이벤트 수준 자료는 관리자가 설정한 최대 14개월 동안 보관될 수 있습니다. Remote Config 설치 식별자, 익명 Auth와 Firestore 랭킹 자료는 운영자가 삭제를 실행할 때까지, 문의 메일은 문의 목적 달성 또는 삭제 요청 처리 시까지 보관합니다. Google의 live·backup 삭제에는 서비스별 추가 처리기간이 적용될 수 있습니다.
거부·영향
진단 공유와 랭킹 참여는 앱 설정에서 거부하거나 철회할 수 있으며 핵심 로컬 사용량 기능은 계속 이용할 수 있습니다. 공개 랭킹 관전 또는 Remote Config 통신을 차단하면 해당 리더보드와 원격 업데이트 안내를 사용할 수 없습니다. 피드백 메일 전송을 취소하면 문의가 접수되지 않습니다. 이미 이전된 정보의 삭제·처리정지는 아래 이메일로 요청할 수 있습니다.

사용자가 틀린 지형 제보를 제출하면 선택한 사진, 촬영 시각, 좌표, 선택적 장소명, 앱 버전·언어가 Firebase에 저장됩니다. 사진은 재인코딩해 원본 EXIF 메타데이터를 제거합니다.
자동 처리
앱 개선을 위해 Firebase Analytics로 비민감 기능 사용, 앱·기기 정보, 앱 인스턴스 식별자와 대략적 지역을 수집합니다. 검색어·좌표·경로명·산책·건강 데이터는 보내지 않습니다. AdMob은 광고 제공·측정을 위한 광고·기기·성능 정보를 처리할 수 있습니다.
보관·삭제
로컬 데이터는 앱 삭제로 제거됩니다. 제보는 접수일부터 180일 뒤 자동 삭제되며, 그 전에 지우려면 이메일로 요청할 수 있습니다.

공통 처리 원칙

  • 앱 기능 제공에 필요한 최소 정보만 처리하고, 광고·분석·알림처럼 선택 가능한 기능은 운영체제 및 지역별 동의 절차를 따릅니다.
  • 앱에서 직접 운영하는 서버 데이터는 HTTPS로 전송하고 Firebase 보안 규칙, App Check, 데이터베이스 접근 제어 등 앱별 보호 조치를 적용합니다.
  • 광고·분석·인증·호스팅 제공자는 자체 인프라에서 기기 정보, IP 주소, SDK 식별자와 기술 로그를 처리할 수 있으며 국외에서 처리될 수 있습니다.
  • 법적 의무, 분쟁 대응, 보안·부정 사용 방지에 필요한 경우를 제외하고 목적이 끝난 데이터는 삭제하거나 식별할 수 없는 집계로 전환합니다.

외부 서비스

각 앱 카드에 표시된 서비스만 해당 앱에 적용됩니다. 서비스 제공자가 처리하는 구체 항목과 보관 방식은 아래 공식 정책에서도 확인할 수 있습니다.

Google Firebase에는 앱별로 명시한 분석·충돌·인증·서버 기능 처리를 위탁하며, 해당 정보는 서비스 제공을 위해 미국을 포함한 국외 인프라에서 네트워크 전송 시점에 처리될 수 있습니다. Apple에는 App Store 결제, DeviceCheck, 푸시 알림 등 사용한 Apple 기능에 필요한 처리를 위탁합니다. 각 앱 카드의 항목·목적·보관 및 삭제 기준이 이 공통 설명보다 우선합니다.

보관·삭제와 이용자 권리

이용자는 본인 데이터의 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 앱 안에 계정 삭제나 초기화 기능이 있으면 그 기능이 가장 빠릅니다. 앱에서 처리할 수 없거나 기기를 사용할 수 없는 경우 아래 이메일로 앱 이름과 요청 내용을 보내주세요.

  • 본인 확인에 필요한 최소 정보만 추가로 요청하며, 요청 처리 후 확인 자료를 지체 없이 삭제합니다.
  • 법령상 보관 의무나 보안·부정 사용 방지상 필요한 데이터가 있으면 항목과 기간을 안내합니다.
  • Google Play에서 계정을 만드는 앱은 앱 내부와 외부 웹 경로 모두에서 삭제 요청 방법을 제공합니다.
  • 앱을 삭제하면 기기 샌드박스의 로컬 데이터는 제거되지만, 서버 데이터나 제3자 SDK 데이터는 별도 삭제 요청이 필요할 수 있습니다.

방침 변경

앱 기능, SDK 또는 법적 요구사항이 바뀌면 이 문서를 갱신합니다. 중요한 변경은 시행 전에 앱 또는 이 페이지에서 알리고, 추가 동의가 필요한 처리는 동의를 받은 뒤 시작합니다. 각 앱의 스토어 Data safety·App Privacy 답변도 실제 처리와 일치하도록 함께 관리합니다.
